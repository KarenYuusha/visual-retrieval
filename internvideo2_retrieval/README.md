# Legacy InternVideo2 commands

Use the [shared baseline guide](../docs/baselines.md) for new runs.
This folder keeps `extract_features.py`, `evaluate_retrieval.py`, `search_video.py`
and `run_datasets.py` as compatibility wrappers over `src/visual_retrieval`.
The corrected tokenizer and compatible caches are retained.
Install dependencies from the repository root; datasets default to `S:\video_retrieval`.
